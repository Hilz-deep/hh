# 星光圣诞树 · A Christmas Wish

一个可以挂照片、用手势旋转的冰蓝粒子圣诞树。使用 WebGL 绘制树身，使用 MediaPipe 在浏览器里识别手势。

基于 [Mzying022/christmas-tree](https://github.com/Mzying022/christmas-tree)（手势交互圣诞树 V2.0）的代码改进而来：夜空改为动态星空与流星，树身加入金色粒子、入场与手势闪亮效果，手势识别放宽阈值并加入手部预览，照片展开改为带动画的放大展开。

树身还加入了经典 Python turtle 圣诞树的节日元素：多彩闪烁装饰灯球（红、黄、绿、粉、天蓝按各自相位错峰明灭）、树顶金色五角星，以及树下带丝带蝴蝶结的彩色礼物盒。这些元素与冰蓝粒子主体融为一体，聚合手势触发时礼物会随粒子一起淡出。

## 开场与 V2 增强功能

- **星空引导页 + 雨落成树入场**：进入前是纯前端的三幕星空封面（发光点、飘雪、动态星空 canvas），轻点任意处或左右滑动切换场景。最后一幕点「点亮圣诞树」进入后，会播放一段约 5 秒的入场演出：所有粒子如雨般从屏幕顶端错峰落下、重力加速堆积在画面底部成一条光带，短暂停留约 3 秒后整堆粒子旋转、螺旋汇聚成圣诞树，礼物与题字在树成形后淡入。WebGL 着色器与 Canvas2D 降级路径都实现了这段演出；开启「减少动态效果」时直接显示成树。
- **To 题字**：场景左侧「To: …」可点击编辑（也支持键盘 Enter），写一句想对 TA 说的话，自动缩放到合适字号并保存在本机。
- **手势训练师**：右上角「训练师」打开面板。开启摄像头后实时显示识别类别与置信度；摆好手势按 1–5（其他/握拳/张开/捏合/OK）即可把当前姿态存进本地训练集。采用 21 关键点的旋转/尺度/平移不变特征 + 距离加权 k-NN，支持撤销、清空、导入导出 JSON。勾选「ML 接管」后由你训练的模型直接驱动手势。数据只存在本机浏览器。
- **OK 手势许愿**：拇指食指成圈、其余三指伸直，粒子如星辰散开并浮现一句随机心愿文案，12 秒后自动收起。
- **张掌星辰散布**：张开手掌时，粒子不再只是恢复成树，而是如星辰般向四周缓缓漂散，挂在树上的照片也随星尘一起漂浮明灭；握拳把它们重新收拢成树。旋掌识别的灵敏度也已提高（更快的平滑、更小的死区、更大的旋转映射）。
- **净屏观赏**：右上角「净屏」或按 P 隐藏所有控件与相册，只留树、照片与心愿，再点一次或 Esc 退出。
- **目录照片自动上树**：`photos/manifest.json`（文件名数组）中列出的图片、以及 `photos/` 下常见命名（如 photo-1.jpg、img-2.png 等）会在启动时被自动探测并挂到树上。纯静态站点无法真正列举目录，因此用清单 + 常见名探测实现等价效果；把图片放进 `photos/` 并在 manifest 中列出文件名即可。

## 本地运行

在仓库根目录执行以下命令，然后打开 http://localhost:8000 。

```sh
python3 -m http.server 8000
```

页面可直接部署到静态托管服务。远程访问时需使用 HTTPS 才能开启摄像头。

## 互动方式

- 上传照片后，照片挂在树上，并保存在当前浏览器的 IndexedDB 中。
- 拇指与食指连续捏合两次，中间松开。第一次放大照片，之后每组双捏合切换到下一张。双捏合的间隔放宽到 1.4 秒，识别前会对手部关键点做平滑，远处或光线稍暗的手也更容易被识别。
- 开启摄像头后，右上角会出现手部预览：骨架、拇指与食指之间的捏合连线、捏合程度条和距离提示（手靠近一点 / 手远一点），可以直观看到手有没有被识别到。
- 握拳收起照片，张开手掌并左右移动可以旋转树（3 根手指伸开即可）。没有照片打开时一直握拳，粒子会缓慢聚成一团光球；伸开手掌，粒子散开恢复成树。照片打开时握拳只收起照片。
- 右上角“音乐”按钮播放经典圣诞歌曲《Jingle Bells》（Web Audio 铃声合成，无音频文件，需点按钮后开始，再点一次关闭）。
- 鼠标或触屏也可以拖动树、点击照片。键盘聚焦树后可用左右方向键旋转。
- 点开照片时，照片会从被点的位置放大展开，带模糊转清晰和金色光晕；切换照片时向左右滑动；收起时缩小淡出。手势触发展开时，圣诞树会闪亮一下。
